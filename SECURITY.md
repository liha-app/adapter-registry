# Security

Do not report vulnerabilities in a public issue or pull request.

Use GitHub's private vulnerability reporting for this repository, or follow the
security contact published by the
[Liha WebMCP Adapter project](https://github.com/liha-app/webmcp-adapter/security).

Adapters are untrusted data even after publication. The Store and extension
must validate them again before installation. Official and Verified badges are
provenance and test signals, not a guarantee that a third-party website will
never change.
